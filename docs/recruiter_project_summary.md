# Recruiter Project Summary

## Project Title

Bank Reconciliation Automation using SQL, Python and Excel

## Business Problem

Finance teams manually reconcile bank statements with ERP records every day. This process is time-consuming and prone to errors, especially when there are duplicate bank entries, missing ERP postings, timing differences, and unmatched payments.

## Solution Built

Built an automated reconciliation engine that compares bank statement transactions with ERP transactions using reference number, signed amount, and transaction date tolerance. The automation generates matched transactions, unmatched bank entries, unmatched ERP entries, duplicate bank transaction groups, and a management summary report.

## Tools Used

* SQL / MySQL
* Python
* Pandas
* Excel output
* CSV datasets
